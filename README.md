# 🎬 AutoCasting Frontend

Este es el proyecto **Frontend oficial de AutoCasting**, una plataforma desarrollada por **Padimasso** para conectar actores y castineras de forma moderna, eficiente y profesional.

La aplicación está construida con:

- ⚛️ **React 19**
- 🎨 **TailwindCSS 4**
- ⚡ **Vite**
- 📦 Integrada con una **UI Library** personalizada: [`AutoCasting-UI-Library`](https://padimasso.atlassian.net/wiki/spaces/AC/pages/3047425/Auto+Casting+UI+Library)

## 🧑‍💻 Requisitos

- Node.js `^18` o `^20`
- pnpm / npm
- Acceso local al repositorio `AutoCasting-UI-Library`

---

## 🛠️ Instalación local

1. Cloná este repositorio:

```bash
git clone https://github.com/PadimassoOrg/AutoCasting-Frontend.git
cd AutoCasting-Frontend
```

2. Install las dependencias:

```bash
npm install
```

3. Verificá que tengas acceso local a la UI Library en ../AutoCasting-UI-Library o tu ruta relativa.

---

## ▶️ Levantar en modo desarrollo

```bash
npm run dev
```

Accedé en: http://localhost:5173/

---

## 🛠️ Scripts disponibles

- npm run dev (Inicia la app en modo desarrollo (vite))
- npm run lint (Ejecuta ESLint sobre los archivos fuente)
- npm run format (Formatea el código con Prettier)
